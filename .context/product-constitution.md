# AnyGate Product Constitution

## Mission

AnyGate is the universal runtime and provider manager for AI coding tools.

It enables developers to use any AI provider with any coding agent through one consistent runtime.

---

## Vision

Developers should configure providers once and use them everywhere.

Claude Code.

Codex.

Gemini CLI.

Cursor.

Continue.

Cline.

Roo.

Aider.

Goose.

Future agents.

---

## Core Principles

### 1. CLI First

The CLI is the primary product.

Everything should be usable from the terminal.

The dashboard exists to complement the CLI, not replace it.

Never build UI-first features.

---

### 2. Runtime First

The Runtime Engine is the heart of AnyGate.

Every launcher.

Every provider.

Every request.

Every dashboard.

Everything flows through the Runtime Engine.

---

### 3. Zero Configuration

Users should be productive within minutes.

Examples:

anygate free

anygate claude

anygate doctor

Configuration should be automatic whenever possible.

---

### 4. Universal Providers

Configure a provider once.

Use it everywhere.

Never duplicate provider configuration.

---

### 5. Universal Apps

Support many AI coding agents.

Adding a new launcher should require minimal work.

---

### 6. Invisible Infrastructure

The runtime should stay out of the user's way.

Health.

Sessions.

Metrics.

Discovery.

Cleanup.

Everything should happen automatically.

---

### 7. Reliability Before Features

Prefer:

- Stability
- Simplicity
- Backward compatibility

over adding more commands.

---

### 8. Excellent Developer Experience

The CLI should:

Teach.

Suggest.

Recover.

Explain.

Never leave users guessing.

---

### 9. Extensibility

Everything should be modular.

New providers.

New launchers.

New routing strategies.

New plugins.

Should integrate without redesign.

---

### 10. Product Scope

AnyGate IS:

- Runtime
- Provider Manager
- Launcher
- Router
- Gateway

AnyGate IS NOT:

- Chat UI
- Notebook
- IDE
- Playground
- Prompt engineering tool
- AI assistant
